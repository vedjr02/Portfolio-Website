# Design System: Vedant Ambre

## Overview

**Creative North Star: "The Desktop, Either Appearance"**

The site is a Mac desktop. The desktop metaphor is structural, not a skin. Each section is an AppKit document window with a unified title bar, traffic lights and an opaque body, and on a mouse-driven screen of 1024px or wider it can be dragged by its title bar. The Dock at the bottom is the navigation, the solid menu bar at the top is the persistent header, Control Center (opened from its menu bar glyph) holds the visitor's settings, Spotlight (⌘K) is search, Quick Look is project detail, and a notification banner is the toast. Every new surface should answer one question first: which piece of macOS would do this job? Then draw that piece.

The world follows the visitor's appearance, as macOS does. Every UI colour is a CSS variable with a light value on `:root` and a dark value on `:root[data-theme="dark"]`, and Control Center offers Light, Dark and Auto (Dark is the default; Auto follows `prefers-color-scheme`). The default wallpaper is the dark Golden Gate photograph, used in both appearances, so text laid directly on the wallpaper (the hero) is always white. The Kildare hills SVG is the alternative wallpaper, with a night overlay in dark appearance. Visitors can also dim the wallpaper by up to 60% with a black overlay. The wallpaper carries the atmosphere and is the only large saturated field on the page.

The desktop runs at the density of macOS itself. Controls are small (13px text, 28 to 36px targets on fine pointers, 44px on coarse), grey chrome is quiet, and a few large system-face headlines carry the content weight. There is one interface accent, system blue, and it does the jobs it does in AppKit: default buttons, selected rows, switches that are on, focus rings and links. Finder tag dots are the only other hues, and they label groups. There is no liquid glass and no backdrop blur anywhere: floating chrome uses the near-opaque vibrant material so every animation stays at 60fps. Confirmed rejections from the product thesis: no card grid of projects.

**Key Characteristics:**
- Two appearances from one token set: light and dark values for every UI colour, switched on `<html data-theme>` with a 350ms colour ease.
- Sections are windows: 12px corners, a 48px chrome title bar with traffic lights, an opaque body, and a three-layer window shadow. Windows can be dragged by the title bar from 1024px.
- Navigation is macOS furniture: a solid menu bar, a vibrant Dock with a running-indicator dot, Spotlight, and Control Center.
- System blue is the only accent. Finder tag colours appear only as small dots.
- One floating material: `vibrant`, a near-opaque neutral (97%) with no backdrop filter, for all chrome over the wallpaper.
- The system face: SF Pro on Apple devices, with Geist as the fallback elsewhere. Headlines use tight negative tracking, and 13px is the control size.
- Motion is spring-based and brief. Every animation collapses under `prefers-reduced-motion` and under Control Center's Focus switch.

## Colors

The palette is macOS in both appearances: near-neutral greys, one system blue and the Finder tag hues, set on a photographed or drawn landscape. Each key below is a CSS variable. The key without a suffix is the light value, and the `-dark` key is the value under `data-theme="dark"`.

### Primary
- **System Blue** (`accent` / `accent-dark`): The single interface accent. It fills the default push button (a fixed `#2b84ff` to `#0a6cff` gradient in both appearances), switches that are on (Control Center rounds, the Hold My Code panel switch), the selected wallpaper ring, text links, the input caret and the focus ring (mixed to 55% in oklab). Dark appearance lifts it to `accent-dark` so it reads on dark chrome. It never colours headlines or decoration.
- **Pressed Blue** (`accent-press` / `accent-press-dark`): Only the `:active` state of the default button.
- **Selection Blue** (`select`): The selected Finder row and the Spotlight highlight. It is the same in both appearances.
- **Selection Soft** (`select-soft` / `select-soft-dark`): Row hover in the Finder list, and the recipient token in the Mail window. Text selection uses `#b3d1ff` on `#0b1f3a`.

### Secondary
- **Golden Hour Sand** (`sky`) / **Night Sky** (`sky-dark`): The page background behind the wallpaper and the `theme-color` for each appearance. Sand is sampled from the Golden Gate photograph.
- **Kildare Deep Green** (`#274a3d`): The darkest ridge of the Kildare wallpaper. The page itself shows no scrollbar. The Kildare SVG steps from haze blue (`#adc6d2`) through sage (`#aabfb6`, `#85a595`, `#638b77`, `#426d5a`) to deep green. Those values belong to the wallpaper and its Control Center thumbnail. They are not UI colours.

### Tertiary (Finder tags)
- **Tag Red / Orange / Green / Blue / Grey** (`tag-red`, `tag-orange`, `tag-green`, `tag-blue`, `tag-grey`): Group labels for Case studies, Consulting, Analytics & data, Products and Experiments. The Flagship tag is Graphite Ink (`ink`). Tags appear only as 10px dots in the sidebar and the Quick Look meta line, and as the badge on folder icons. Tag Orange also marks "In progress". The tag hues are the same in both appearances.
- **Status Live** (`live` / `live-dark`): The 7px "Live" status dot, the "Holding" dot and the "working" pill in the Hold My Code panel (pill fill at 20%).

### Neutral
- **Graphite Ink** (`ink` / `ink-dark`): Primary text, the VA menu-bar mark and the notification app tile.
- **Ink Secondary** (`ink-2`): Body and lead paragraphs, and section headers in Control Center tiles.
- **Ink Tertiary** (`ink-3`): Metadata, list columns, captions, detail lines and placeholders.
- **Ink Quaternary** (`ink-4`): Bullet dots, the "Built" and "Idle" status, and the faintest placeholders.
- **Window** (`window`): Window bodies and list rows.
- **Surface** (`surface`): Raised content inside a window or panel: inset lists, Quick Look's README page, focused search fields, the selected segment, and Control Center tiles (at 55%). In light appearance it equals `window`. In dark appearance it is one step lighter, so inset content still lifts.
- **Chrome** (`chrome`) / **Chrome 2** (`chrome-2`): Title bars and window footers, and the backdrop behind Quick Look media.
- **Sidebar** (`sidebar`): Source-list sidebars and the inactive Toolkit window body.
- **Zebra** (`zebra`): Alternate rows in the Finder list.
- **Fill** (`fill`) / **Fill 2** (`fill-2`): Translucent control fills. `fill` is the resting search field, segmented-control track and hover state. `fill-2` is the current menu item, a toggle that is off, the slider track and the progress-bar track.
- **Menu Bar** (`menubar`): The menu bar, which is solid in both appearances.
- **Vibrant** (`vibrant`): The vibrancy material (see Elevation & Depth).
- **Plain Button** (`plain-bg`, `plain-hover`, `plain-press`): The plain push button in its rest, hover and pressed states.
- **Rule** (`rule`): Hairline dividers and the 0.5px edge rings drawn with `var(--rule)`.

### Named Rules
**The Token Or Nothing Rule.** Every UI colour goes through a CSS variable that has both a light and a dark value. A literal hex on a surface is a bug in one of the two appearances.

**The One Accent Rule.** System blue is the only interface colour. If something needs to look pressable, selected, on or focused, it turns blue. If not, it stays grey.

**The Tag Dot Rule.** Finder tag colours label groups and do nothing else. They show up as dots of 10px or smaller, or as folder badges. They never fill buttons, text, backgrounds or headings.

**The Wallpaper Owns Colour Rule.** Big saturated areas belong to the wallpaper. Windows, bars and panels stay neutral or vibrant.

### Named exceptions (literal colours outside the token set)
These appear once, reproduce a real object, and are not to be reused:
- **Traffic lights:** red `#ff5f57`, yellow `#febc2e`, green `#28c840`, and grey `#d6d6d5` when inactive.
- **Dock and Spotlight brand tiles:** LinkedIn `#0a66c2`; GitHub on Graphite Ink; the Mail tile gradient from `#3fa0ff` to `#0a6cff` with a `#7fb6ff` flap; the Case studies tile from white to `#e9ecef` with a `#c9ced4` page and tag-coloured bars; the About tile ground `#c9d6cf`; the folder icon blues `#5fa4e8`, `#8cc4f5` and `#b9dcfa`.
- **Hold My Code panel usage bar:** green `#30c253`, copied from app 2.5.1.
- **Mail recipient token text:** `#0b4fbf` on `select-soft`.
- **Kildare wallpaper and thumbnail:** the SVG ramp above, plus the dark-appearance night overlay `#0c1320` at 70% multiply.

## Typography

**Display Font:** the system face: -apple-system / SF Pro Display (Geist on non-Apple devices)
**Body Font:** the system face: -apple-system / SF Pro Text (Geist fallback)
**Mono Font:** Geist Mono (400, 500; with ui-monospace, SF Mono, Menlo)

**Character:** The site speaks in the Mac's own voice. On Apple hardware that is SF Pro, and elsewhere Geist stands in because it reads as neutral system UI at 13px. Headlines are set at 600 with tight negative tracking. The body carries a slight global tracking of -0.006em.

### Hierarchy
- **Display** (600, clamp 2.6 to 5.4rem, 0.98, -0.03em): The hero thesis headline only, with balanced wrap.
- **Headline Flagship** (600, clamp 2 to 3.25rem, 1.02, -0.035em): The Hold My Code window title only.
- **Headline** (600, clamp 1.6 to 2.25rem, 1.05, -0.03em): Titles inside a window or sheet, such as the Quick Look project name, the active case study (clamp 1.6rem, 3vw, 2.2rem at 1.08) and the About name (clamp 1.75rem, 3vw, 2.25rem). These are three tunings of one role. New surfaces should use the token.
- **Lead Hero** (400, clamp 1.05 to 1.25rem, 1.5): The hero lead under the display headline.
- **Title** (600, 22px, -0.02em): Sub-heads inside a window ("What it does").
- **Lead** (400, 17px, 1.5): The summary line under a headline. At 600 it serves as a small sub-head in the Hold My Code window.
- **Body** (400, 15px, 1.6, max 62 to 65ch): Descriptions in windows and Quick Look. Hero buttons also step up to 15px.
- **Body Compact** (14.5px): Longer descriptive text in the case-study pane and Quick Look.
- **Control Large** (550, 14px): Push buttons. Also the hero info card, Spotlight row labels and the Mail subject line.
- **Meta** (13.5px, Ink Tertiary): Meta lines under a headline, Finder footer text and grouped-list rows.
- **Control** (13px): The macOS control size. Used for window titles (600), menu bar items, sidebar items, list rows (500 for names), search fields, small buttons, notification text and Control Center tile titles (600).
- **Caption** (12.5px): Tooltips, Spotlight hints, the hero panel caption, Control Center section headers (600, Ink Secondary), group headers in the Toolkit window (600, Ink Tertiary) and the README mono page.
- **Label** (12px): List headers, window subtitles, tabular counts and Control Center choice labels. This is also the base size of the Hold My Code panel.
- **Detail** (11.5px, Ink Tertiary): Secondary lines in Control Center tiles, Spotlight group headers (600) and the panel's segmented control.
- **Micro** (11px): The smallest caption ("Now shipping"), and the panel's pills and footnotes.
- **Mono** (400, 12.5px, 1.7): Quick Look's README preview, plus the one kaomoji sticker.

Two sizes exist only for input mechanics. Mobile inputs are 16px so iOS does not zoom (Mail fields, the mobile search field). The Spotlight field is 20px, rising to 22px at `sm`, at weight 300. The VA mark in the menu bar is a 9px bold monogram inside an 18px tile.

### Named Rules
**The System Size Rule.** Chrome speaks at 13px. Anything that is part of the desktop (menu, sidebar, list, title bar, field, Control Center tile) sits between 11 and 13px. Only content inside a window grows beyond 13.5px.

**The Sentence Case Rule.** Group headers are small, semibold and in sentence case, as in the Finder sidebar and Control Center. Numbers in lists, clocks, counts and money use tabular figures.

**The Hold My Code Exception.** The Hold My Code panel copies the shipped app 2.5.1, so it uses the app's own compact type: 10.5px uppercase labels at 0.04em tracking, and 10.5 to 11px captions. This type lives only inside that panel.

## Layout

A single scrolling desktop. The menu bar is fixed at the top (36px plus the safe-area inset), and from `md` (768px) the Dock is fixed and centred at the bottom. The wallpaper is fixed behind everything. Between the two bars, each section is one window (or a pair of overlapping windows) centred in a 1180px content column. The Mail window narrows to 820px. Sections pad 40px vertically on mobile and 64px from `sm` (640px). Horizontal page padding is 12 to 16px on mobile and 32px from `sm`. `scroll-padding-top: 56px` keeps anchored windows clear of the menu bar.

Windows use a source-list pattern. From `md` (768px) a fixed sidebar (13.5rem in Projects) sits beside a flexible content pane. Below `md` the sidebar becomes a horizontally scrolling strip above the content. Window bodies pad 20px on mobile and 32px from `sm`. The Finder list adds columns as the viewport widens: Kind from `md`, Built with from `lg` (1024px). On small screens the kind moves under the name.

The hero is the one section without a window. The hero sets white type straight on the dark wallpaper at left: the name as the title (clamp 3.4 to 7.5rem, bold), "Business analyst who ships software." as a large subtitle (clamp 1.75 to 2.9rem, white at 85%), a lead paragraph (white at 70%), the two buttons, and an info list under a white 15% hairline. From `lg`, the Hold My Code panel hangs from its menu bar icon at top right and the copy column narrows to leave it room. Below `lg`, the panel flows under the buttons. Control Center drops from the top right, 44px below the top edge, at `min(21rem, 100vw - 1rem)`.

The desktop has three responsive thresholds beyond the breakpoints. Windows become draggable from 1024px on a fine pointer. Dock magnification needs a fine pointer and at least 640px. Desktop stickers appear only from 1360px on a fine pointer, and only while Control Center's Desktop icons switch is on. On coarse pointers buttons rise to 44px and small buttons to 40px.

## Elevation & Depth

Depth is lifted and layered, as in macOS. Every opaque floating surface is edged by a 0.5px hairline ring inside its shadow stack, with a soft, diffuse drop underneath. In light appearance the window drop is tinted warm (`rgba(40,28,16,…)`) so windows sit on the Golden Gate photograph. In dark appearance the ring turns white at 14% and the drop deepens to black. There are three materials:

- **Opaque:** windows, sheets and Spotlight.
- **Vibrant:** `background: var(--vibrant)` with `backdrop-filter: blur(24px) saturate(1.8)`. Used on tooltips, the Hold My Code panel, the hero info card and panel caption, notifications and the Mail footer.

### Shadow Vocabulary
- **Window** (`--window-shadow`): light `0 0 0 0.5px rgba(0,0,0,0.22), 0 2px 6px rgba(0,0,0,0.06), 0 24px 60px -12px rgba(40,28,16,0.4)`; dark `0 0 0 0.5px rgba(255,255,255,0.14), 0 2px 6px rgba(0,0,0,0.3), 0 30px 70px -12px rgba(0,0,0,0.7)`. For focused windows and the Quick Look sheet.
- **Window Inactive** (`0 0 0 0.5px rgba(0,0,0,0.18), 0 12px 30px -12px rgba(16,38,30,0.3)`): For a window behind the focused one, paired with grey traffic lights and an Ink Tertiary title.
- **Window Dragging** (`0 0 0 0.5px rgba(0,0,0,0.22), 0 36px 80px -16px rgba(16,38,30,0.5)`): While a window is being dragged, it lifts.
- **Menu** (`--menu-shadow`): light `0 0 0 0.5px rgba(0,0,0,0.18), 0 12px 32px -6px rgba(0,0,0,0.28)`; dark `0 0 0 0.5px rgba(255,255,255,0.14), 0 14px 36px -6px rgba(0,0,0,0.6)`. For popovers and floating chrome: tooltips, notifications, the hero info card, the Hold My Code panel and Control Center.
- **HUD** (`0 0 0 0.5px rgba(0,0,0,0.2), 0 30px 80px -20px rgba(0,0,0,0.5)`): Spotlight, the highest floating layer.
- **Inset Media** (`0 0 0 0.5px rgba(0,0,0,0.2), 0 8px 24px -8px rgba(0,0,0,0.25)`): Screenshots and photos inside a window body.
- **Hairline** (`0 0 0 0.5px var(--rule)`, or a black ring at 0.07 to 0.14): Grouped lists, inset cards and Control Center tiles. An edge with no drop.
- **Sticker** (`drop-shadow(0 5px 12px rgba(0,0,0,0.18))`): Desktop stickers.

### Named Rules
**The Hairline Edge Rule.** Opaque and vibrant surfaces are edged by a 0.5px ring inside the shadow stack, never by a 1px CSS border. Real borders are only for internal dividers (`rule`).

**The Focus Stack Rule.** Only one window reads as focused at a time. It gets coloured traffic lights and the full window shadow. Any window stacked behind it goes inactive. A dragged window rises to the top of the stack.

## Shapes

The shapes follow macOS's continuous rounded rectangles, with the radius set by the size and role of the surface. List rows, sidebar items and selected segments use 6px. Fields, tooltips and small buttons use 7px. Push buttons, segmented tracks, Spotlight rows and wallpaper thumbnails use 8px. Inset cards, grouped lists and the panel's cards use 10px. Windows use 12px. Quick Look and the Hold My Code panel use 14px. Notifications and Control Center tiles use 16px. Spotlight uses 18px. The Dock uses 22px and Control Center 24px. App tiles use the squircle proportion (`22.5%`), and small app-icon tiles 9px. Status dots, tag dots, traffic lights (12px), the Dock indicator (4px), Control Center toggle rounds (32px), switches and slider tracks are full pills. On mobile, Quick Look becomes a bottom sheet with only its top corners rounded. Thumbnails and screenshots take a tight 4 to 6px radius so they read as documents, not cards.

## Components

### Buttons
Push buttons, drawn the way AppKit draws them.
- **Shape:** Gently rounded (8px). Minimum height 36px (44px on coarse pointers), 14px at weight 550. Hero buttons step up to 44px, 20px padding and 15px text.
- **Default:** A System Blue gradient (`#2b84ff` to `#0a6cff`) with white text. A 0.5px inner top highlight, a dark-blue 0.5px ring and a 1px drop give it the lit look of an AppKit default button. Use one per window, for the primary action.
- **Hover / Active:** Hover deepens the gradient (`#1f7bff` to `#0063ee`). Active flattens to `accent-press` and nudges down 0.5px. Transitions run 120ms ease.
- **Plain:** `plain-bg` with a 0.5px ring and a 1px soft drop, and ink text. It moves to `plain-hover` on hover and `plain-press` when pressed. Used for secondary actions ("Email me", "Source", "Copy").
- **Small:** 7px radius, 29.6px tall, 13px. Used for title-bar toolbar actions.
- **Icon buttons** in title bars and the menu bar: 28px tall and 36px wide, 6px corners, transparent until hover (`fill`). The current or open state uses `fill-2`. Lucide line icons or drawn SVG glyphs at 14 to 16px.

### Segmented Control
- **Style:** A `fill` track with 8px corners and 2px padding. The selected segment is `surface` at 6px corners with a soft drop. The unselected segment is Ink Secondary or Tertiary. Used for the Hold My Code media toggle and the keep-awake mode.

### Cards / Containers
- **Windows** are the container. There are no free-floating cards on the page. Inside a window, grouped content sits in `surface` inset lists (10px corners, hairline ring, `rule` dividers, 10 by 14px row padding) on a Sidebar ground.
- **Vibrant info card:** Only on the wallpaper (the hero's Based in / Studying / Available list). 18px corners, 20 by 16px padding, 14px text, Menu shadow.

### Inputs / Fields
- **Search field:** A `fill` background, 7px corners, 28px tall, with a leading 14px search glyph in Ink Tertiary and 13px text. On focus it turns `surface` with a 3px `rgba(10,108,255,0.35)` ring. On mobile it is 40px tall with 8px corners and 16px text.
- **Mail fields:** Borderless labelled rows ("To:", "Subject:" in a 64px Ink Tertiary column) separated by `rule` hairlines. The body is a transparent textarea at 15px (16px on mobile) and 1.55.
- **Spotlight field:** 20 to 22px light weight, borderless, with a 20px search glyph.
- **Slider (Control Center):** A 22px pill track in `fill-2` with a 22px white thumb, a 0.5px ring and a 1px drop.

### Navigation
- **Menu bar:** Solid `menubar`, 36px, a 6% black bottom hairline, 13px text. At left are the VA mark (an 18px Graphite Ink tile with a 5px radius) and the bold name, followed by section items (28px, 6px corners, hover `fill`, current `fill-2` with `aria-current="location"`). At right are the Hold My Code glyph, the search button, the Control Center glyph (two toggle pills) and a live Europe/Dublin clock in tabular figures. Section items hide below `md`.
- **Dock:** Real macOS app icons only (Finder for Projects, Hold My Code, Preview for Case studies, Contacts for About, Mail for Contact, then Safari for LinkedIn and Terminal for GitHub), taken from the system .icns files into `public/dock/`. No photos, no brand logos. Vibrant at 22px corners, centred at the bottom. Tiles are 50px. Phones have no Dock. On fine pointers they magnify toward the cursor (50 to 76px within 140px, spring 380/28), unless Focus is on. A vibrant tooltip rises above a tile on hover or focus. A 4px ink dot at 75% marks the section in view. A 1px divider (black at 15%) separates sections from external links.
- **Finder sidebar:** Source-list items at 32px with 6px corners. Each has a tag dot or folder glyph, a label and a tabular count. The selected item is `fill-2` at weight 500.

### Control Center (signature)
The visitor's settings, drawn as macOS Control Center. It is a 21rem vibrant panel at 24px corners with 12px padding, dropping from its menu bar glyph at top right in a 160ms tween (from y -6 and scale 0.98, origin top right). Escape or a click outside closes it. Inside is a two-column grid of opaque `surface` tiles (16px corners, hairline ring), in this order:
- **Appearance:** a radiogroup of three 32px rounds (Light, Dark, Auto). The selected round is `accent` with white glyphs, and the rest are `fill-2`.
- **Focus** and **Desktop icons:** half-width switch tiles, each with a 32px round, a 13px semibold title and an 11.5px Ink Tertiary state line. Focus pauses all motion site-wide. Desktop icons hides the stickers.
- **Available for work:** a full-width action tile (always-on round) that copies the email address and raises a notification.
- **Wallpaper brightness:** a slider between two sun glyphs (0 to 60% dim).
- **Wallpaper:** a radiogroup of two 16:10 thumbnails at 8px corners. The selected thumbnail gets a 2.5px `accent` ring and a semibold label. The Golden Gate thumbnail follows the appearance.
- **Now shipping:** a now-playing tile with the 40px app icon, an 11px "Now shipping" line, the 13px semibold name and version, and a `fill-2` play round that scrolls to the Hold My Code window.

Settings are kept per visitor in localStorage (the defaults are Auto, Golden Gate, no dim, icons on, Focus off), and every read and write is guarded.

### Finder List (signature)
The single index of every project. The header is sticky, `window` at 95%, with 12px Ink Tertiary column labels and sortable Name and Date (a chevron shows direction). Rows are one line, 36px (40px on mobile), with zebra striping (`window` / `zebra`) and a `select-soft` hover. A selected row fills `select` with white text, and white at 80 to 85% for secondary columns. A click, Return or Space opens Quick Look. A chrome footer shows "n of N items" and the keyboard hint.

### Quick Look (signature)
A modal sheet, 860px wide with 14px corners, with the Window shadow over a green-tinted scrim (`rgba(20,35,30,0.28)` with a 2px blur). The chrome title bar holds close and previous/next icon buttons and a centred title with a position count. Media is 16:9 on `chrome-2`. Projects without media show a README page in Geist Mono on `surface`. It enters with a spring (380/32). On mobile it becomes a bottom sheet.

### Spotlight and Notification
- **Spotlight:** A 640px HUD at 18px corners with a heavy backdrop blur, placed 16vh from the top. Results are grouped under 11.5px sentence-case labels. Each row is 40px with 8px corners, a 28px icon tile and a 12.5px hint. The active row fills `select`. It opens with a spring (520/36).
- **Notification:** A vibrant banner at 16px corners, 352px wide, at top right under the menu bar. It holds a 36px Graphite Ink app tile at 9px corners, a 13px semibold title and an Ink Secondary body, and springs in (420/34).

### Window
The primary container. It has a 48px `chrome` title bar with traffic lights (12px, each with a 0.5px inner ring). The 13px semibold title can carry an optional 12px subtitle, and toolbar controls sit at right. A `rule` hairline separates the title bar from the `window` body. The first time a window scrolls into view it opens from scale 0.97, 24px lower and transparent, with a spring (260/30). On fine pointers from 1024px the title bar is a grab handle: dragging lifts the window to the top of the stack with the Dragging shadow, and a double-click springs it back to place (320/30).

### Hold My Code Panel (signature, documented exception)
A working copy of the Hold My Code 2.5.1 menu bar panel: a vibrant 20rem panel at 14px corners with the Menu shadow, 12px base type, and cards in `surface` at 70% with 10px corners. It has a Refresh pill, a 38 by 22px `accent` switch, agent rows with `live` "working" pills, a keep-awake segmented control, usage bars (5px, `fill-2` track, the app's `#30c253` fill) and a four-up tabular stats row. Its 10.5px uppercase labels and 10.5 to 11px captions copy the real app and are not house style (see Typography).

### Stickers
Desktop clutter in the style of holdmycode.xyz: raster Finder icons (folder, terminal, settings), a beachball and a mono kaomoji, scattered on the hero at slight rotations (plus or minus 12 degrees) with the Sticker drop. Every sticker can be picked up and dragged (scale 1.07 while dragging). The layer is decorative and `aria-hidden`. It appears only at 1360px or wider on a fine pointer, and Control Center's Desktop icons switch hides it.

## Do's and Don'ts

### Do:
- **Do** put every new section in a Window with traffic lights, a 13px semibold title and a 12px corner radius. Choose the macOS app that would do the job (Finder, Mail, Quick Look, Preview) and draw its chrome.
- **Do** take every UI colour from a CSS variable that has both a light and a dark value, and check the surface in both appearances.
- **Do** keep System Blue (`accent`, `select`) for default buttons, selection, on-states, focus and links only.
- **Do** use the vibrant material with the Menu shadow for chrome floating over the wallpaper. **Don't** add backdrop-filter, SVG displacement or blur animations; they cost frames.
- **Do** edge opaque and vibrant surfaces with a 0.5px ring inside the shadow.
- **Do** set type from the recorded ramp (11, 11.5, 12, 12.5, 13, 13.5, 14, 14.5, 15, 17, 22px and the clamp display sizes), keep chrome text at 11 to 13px, group headers in sentence case, and figures tabular.
- **Do** open detail in Quick Look or a sheet, and keep the page itself to one-line rows.
- **Do** use springs for opening surfaces and 120ms ease for control states, and honour both `prefers-reduced-motion` and the Focus switch.

### Don't:
- **Don't** introduce a second interface accent. Finder tag colours stay as dots of 10px or smaller and as folder badges.
- **Don't** hardcode a light-only colour (a white background, a black hairline, an `rgba(248,…)` panel) on a surface that has to work in dark appearance.
- **Don't** put a dark hero band on the page. Dark appearance darkens the whole desktop at once, and no section is dark on its own.
- **Don't** lay projects out as a grid of cards. Projects are rows in the Finder list.
- **Don't** use 1px CSS borders as the outer edge of an opaque or vibrant floating surface. Use the 0.5px ring.
- **Don't** fill large areas with saturated colour inside windows or bars. That field belongs to the wallpaper.
- **Don't** use uppercase letter-spaced labels as section or group headers on new surfaces. The group-label pattern is sentence case. The only exception is the Hold My Code panel, because it copies the shipped app's UI.
- **Don't** add type sizes below 11px outside the Hold My Code panel.

## Phone layout (iOS)

Below the `md` breakpoint (768px) the desktop becomes an iPhone. Desktop windows, the demo panel and the hero info line are hidden; each section renders an iOS counterpart from `src/components/mobile/`:

- **Status bar** instead of the menu bar: 24-hour Dublin time at left (15px semibold), Spotlight and Control Center at right, 44px tall.
- **Hold My Code** as an App Store product page: 112px icon at 24px corners, 22px semibold name, a blue "Get" pill, a horizontally scrolling info strip (Version, Agents, Runs on, Price, Developer), What's New, a swipeable Preview carousel (video first), a three-line description with "more", and an Information list.
- **Case studies** as swipeable cards (82% width, 18px corners, snap).
- **Projects** as filter chips over an inset grouped list showing six rows, then "Show all". Rows open Quick Look as a bottom sheet with a grabber.
- **About** as a Contacts card: round photo, name, grouped rows, story clamped to four lines, toolkit chips.
- **Contact** as a Settings list with coloured 29px glyph tiles.
- **No Dock.** Sections are reached by scrolling, or through Spotlight in the status bar.

The iOS type ramp is 11, 13, 14, 15, 16 (table rows), 18 (card titles), 20 (in-page headings), 22 (app name), 28 (contact name) and 30px (large section titles). These sizes belong to the phone layout only; the desktop keeps the macOS ramp.
